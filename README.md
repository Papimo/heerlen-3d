# Heerlen 3D
Interactieve 3D-kaart van de gemeente Heerlen: echte gebouwen (3D BAG) op het terrein (AHN), zoeken, plekken (koffie, eten, winkels …) en eigen pins, met een isometrische speelgoed-look.

Live: https://papimo.github.io/heerlen-3d/

Bronnen: 3D BAG (TU Delft), AHN, PDOK/Kadaster, © OpenStreetMap-bijdragers.
